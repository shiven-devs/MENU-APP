## What I learnt

### Visual design

- A sparse grid with large cells reads as **seating / a map**, not a QR. QRs are **many small modules**. If the metaphor is “scan this,” match the real object.

### Git identity vs who may deploy

- Vercel (and GitHub) care about the **commit author email**, not who clicked merge. If the email is not on the GitHub user that owns the project, production can refuse the deploy.
- Cursor agent commits are convenient locally; they are a liability if the agent’s git user is not you. For this repo, **I own the commits**.

### Branches

- Feature work on `cursor/…`, then merge to `main` and delete the feature branch, keeps `main` as the one deployable line.
